# Monopoli WNI Simulator

Monopoli, tapi isinya WNI.

Game monopoli online dengan sentuhan lokal Indonesia. Main bareng teman, rebutan properti, nagih uang sewa, sampai bikin lawan bangkrut.

**Main langsung di sini:**

https://monopoli.wnisimulator.web.id

## Cara Main

- Buat room dan ajak teman untuk bermain.
- Pilih karakter yang ingin digunakan.
- Lempar dadu untuk menentukan langkah.
- Beli properti yang belum dimiliki pemain lain.
- Kalau berhenti di properti lawan, siap-siap bayar sewa.
- Kumpulkan properti dan kembangkan aset untuk memperbesar pemasukan.
- Manfaatkan kartu kesempatan dan hadapi kejadian tak terduga.
- Jaga keuangan supaya nggak bangkrut duluan.

## Yang Ada di Dalam Game

- Multiplayer online, main bareng teman dalam satu room.
- Berbagai pilihan karakter dengan suara dan dialog masing-masing.
- Animasi lempar dadu interaktif.
- Sistem jual beli dan kepemilikan properti.
- Pembayaran uang sewa antar pemain.
- Pengembangan properti untuk meningkatkan harga sewa.
- Kartu kesempatan dan kejadian acak.
- Sound effect dan background music.
- Dialog karakter yang muncul selama permainan.
- Pengaturan kecepatan permainan melalui room lobby.

## Tujuan Permainan

Kumpulkan properti sebanyak mungkin, kelola uang dengan benar, dan pastikan teman-temanmu yang kehabisan uang lebih dulu.

Karena di sini, teman sendiri bisa jadi lawan bisnis paling menyebalkan.
